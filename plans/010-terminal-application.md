# 010 — Build the interactive terminal application

User clarification (2026-11-09): colored readline output still feels basic. Deliver an actual terminal application with the interaction quality of modern coding CLIs: a persistent composer, command picker, scrollable session output, keyboard navigation, responsive welcome/workspace view, status strip and real working/elapsed feedback. Use independent Persistara artwork/wording and copper/neutral colors. Do not copy Sofer or another product's implementation or brand. Sofer's TUI was inspected as behavioral context only; no new source is imported.

Use a pinned terminal renderer over the existing TerminalShell/TerminalClient/services. New UI state is ephemeral; durable missions/receipts remain in the canonical journals. No model simulation, inference, new enrollment, generic shell executor or wallet key access. Only real TTY interactive sessions use the application. Preserve JSON, operator commands and an explicit `--plain` readline fallback; dumb terminals and non-TTY interactive QA stay plain. Respect NO_COLOR. Exit/interrupt must restore raw mode, cursor, paste and screen state after draining owned work. Unknown wallet outcomes remain fenced.

Implement command suggestions with descriptions/arrow navigation, safe draft editing, command-only in-memory history, form/review prompts with fresh input, and transcript paging. Pasted multiline text is input data, never a queue of commands or approvals. Enter/Tab must never silently approve a financial or owner review. All untrusted text is escaped before rendering; byte/message/input bounds prevent unbounded session state. Review fields/digests remain available in scrollback; no tokens, signatures or typed review answers are logged or persisted.

Verify the actual renderer at desktop/narrow dimensions, menu/keyboard/composer/scroll behavior, cancellation and pasted input, real-engine mission creation/review/reopen boundaries and graceful exit. Run TypeScript, browser regressions and required contract checks. Exercise a real PTY and public read/off-chain owner login with no upload/transaction/inference, and inspect a terminal-emulated capture of the actual rendered screen. Record completed behavior, evidence and remaining limitations; do not call this AI conversation or complete conversational session recovery.
